# Technician Note — COOLANT_PUMP_02 Thermal Shutdown
**Asset**: COOLANT_PUMP_02 | **Shift**: B | **Tech**: Vikram Singh

Machine tripped on high-temp alarm. Found coolant filter completely blocked with aluminum swarf.
Coolant flow had dropped to almost nothing. Replaced filter cartridge and flushed delivery lines.
Also found partial blockage in the return line — cleared with compressed air.
Post-repair: temperature stabilized at 40°C, flow restored to 18 L/min. Added filter change to weekly PM.
