# Technician Note — CNC_04_SPINDLE RPM Instability
**Asset**: CNC_04_SPINDLE | **Shift**: B | **Tech**: Amit Nair

Operator reported inconsistent surface finish. Investigation found RPM oscillating ±200.
Checked VFD parameters — all correct. Motor electrical tests normal.
Found coupling elastomer insert severely worn with chunks missing. Causing intermittent backlash.
Replaced coupling insert and re-aligned motor to spindle. RPM now stable within ±10.
Root cause: excessive radial load from misaligned workholding fixture — corrected.
